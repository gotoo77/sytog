# Documentation SYTOG

## Convention linguistique

- Le français est la version canonique et utilise le nom `page.md`.
- La traduction anglaise utilise le nom `page.en.md`.
- Les deux fichiers commencent par un sélecteur réciproque :
  `[Français](page.md) | [English](page.en.md)`.
- Une modification normative doit mettre à jour les deux versions dans le même
  changement.
- Les documents existants uniquement en anglais seront migrés progressivement ;
  cette convention s’applique immédiatement à toute nouvelle documentation.
