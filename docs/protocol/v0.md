# Protocol V0

The JSON envelope contains `family`, numeric `version`, `message_id`,
`session_id`, `sender_id`, `message_type`, optional `revision`, and `payload`.
Family is `sytog`; version is `1`.

Unknown families and versions are explicit errors. Message and participant ids
are opaque strings in V0. The fixture `fixtures/protocol/envelope-v1.json` is a
compatibility contract.

Internal events have a unique `event_id`, monotonic `sequence`, repeatable
`causation_id`, `actor`, and tagged event data. `EventLogV0` adds
protocol/schema versions, `session_id`, and
`base_revision`; validation rejects gaps and duplicate `event_id` values.
Several events may share the command `message_id` as their `causation_id`.
`SnapshotV0`
binds the same versions to a session and revision. Authentication, signatures,
and
wire-level snapshot negotiation are required before hostile networking and are
not falsely claimed by V0.

Breaking changes require a new protocol version, migration notes, and retained
fixtures. Additive fields must define behavior for older readers before release.
