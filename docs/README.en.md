# SYTOG (SYnchronize TOGether) Documentation

## Language convention

- French is canonical and uses the `page.md` filename.
- The English translation uses `page.en.md`.
- Both files begin with a reciprocal language switch:
  `[Français](page.md) | [English](page.en.md)`.
- A normative change must update both versions in the same change.
- Existing English-only documents will migrate progressively; this convention
  applies immediately to all new documentation.
